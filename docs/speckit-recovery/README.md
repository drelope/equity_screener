# SpecKit Recovery Package

This directory contains the recovered planning, requirements, governance, migration, and validation artifacts for the existing equity/dividend research platform.

## Artifact stages

- `00-discovery/` — repository inventory and system mapping.
- `01-audits/` — bias, determinism, price-adjustment, and testing audits.
- `02-requirements/` — recovered requirements, RTM, and coverage statistics.
- `03-constitution/` — draft constitution and principles evidence.
- `04-migration/` — migration readiness, roadmap, and risk register.
- `05-speckit/` — recovered spec/plan/tasks drafts.
- `06-execution-prep/` — decision trackers, exception templates, and external-action packages.
- `07-recommendations/` — recommended remediation sequence.
- `08-implementation-validation/` — implementation evidence, candidate SQL, rehearsal results, and the non-promotion closeout gate.
- `09-future-vision/` — external, non-normative future-state references. See [AI-IOS traceability](09-future-vision/AI-IOS-traceability.md).

## Active SpecKit feature

The active feature state is tracked outside this directory at `specs/001-p0-recovery/`. The P0 specification is at [specs/001-p0-recovery/spec.md](../../specs/001-p0-recovery/spec.md).

Nothing in this package grants approval, promotes a candidate migration, or authorizes production cutover. Human approvals and external evidence remain required.
