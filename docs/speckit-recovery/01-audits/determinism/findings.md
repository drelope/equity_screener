## 4. Severity Rationale

- **High** findings either make a past state unrecoverable (DA-02, DA-03, DA-05, DA-12, DA-16), let a later run silently change what the backtest reads (DA-09, DA-10), or make the runtime itself non-reproducible (DA-17). DA-01 is High because every replay path can silently depend on the run date.
- **Medium** findings are real provenance or determinism gaps with bounded current impact: a correct as-of reader is unused (DA-04), a cache/verdict or ordering choice can change but is small or latent (DA-06, DA-07, DA-08, DA-21), audit records are incomplete (DA-11, DA-13), history can be lost through maintenance (DA-14, DA-15), a checkpoint is overwritten (DA-18), tests do not protect the controls (DA-19), or reports use the current date (DA-20).
- No Low finding is filed: each item either loses evidence or changes a result under a plausible condition. DA-08 and DA-21 are the closest to Low and are marked latent/Unknown.

| Checkpoint contract | `make_checkpoint` records policy/model/feature/data versions and `contract_drift` retires mismatches | Not persisted to `audit.model_runs`; no code/data/env hash (DA-10) |
| Walk-forward controls | Labels sorted before cuts; purge uses the label horizon; folds require all folds; skipped folds fail closed | No regression tests (DA-19) |
| Quarantine is append-only | `audit.quarantined_values` keeps the value, rule, detection, and resolution | Quarantined rows remain in source tables; consumers must exclude them |
| Latest-only projections are explicit | `raw.ticker_profile` is documented as the latest projection of `raw.ticker_profile_load` | Same separation is not applied to SEC payloads, macro, or dividends |

## 6. Limits

- No pipeline, backtest, or model run was executed. The audit proves mechanisms and current stored state; it does not measure how often a nondeterministic branch changes a result.
- The provider/ordering hazards in DA-08 are latent: the warehouse currently holds only `OPENBB` prices with zero duplicate keys. The finding is about future silent change, not a current wrong value.
- The run counts and row counts are a snapshot of the live warehouse on 2026-11-15; runs stored outside the database or artifacts outside the repo were not searched.
- The filesystem archives for identity maintenance were not enumerated; the finding relies on the writer code and its documented archive path.
- DA-21 is Unknown: no duplicate-key batch was executed, because that would require a write.
