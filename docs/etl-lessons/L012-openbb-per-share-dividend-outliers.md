# L012 A per-share dividend ceiling does not transfer between providers

- **Status:** guarded
- **Area:** dividend ingestion and feature annualization (OpenBB per-share amounts)
- **Symptom:** `raw.dividend_data` held 65 OPENBB rows above `$1,000,000` per share, topped by TOPS at `$226,799,993,000,000` on 2006-03-28. The SEC path had refused amounts above `$1,000` since the aggregate-tag fix, but the OpenBB path accepted them.
- **Root cause:** `MAX_PER_SHARE_DIVIDEND = 1000.0` was applied only in `normalize_sec_dividend_rows`. OpenBB/yfinance history is not fully split-restated, so a valid pre-split payment can be tens or hundreds of thousands of dollars per unadjusted share (SUNE `$96,000` at a roughly `$1.74M` price is about a 5.5% yield; CMCT's roughly `$205,000` event is about 3.4%). A blanket `$1,000` OpenBB cap would discard that history. The actual defect is the far tail, and the feature CTE summed it without any ceiling.
- **Detection:** Read-only audit: `provider='OPENBB' AND COALESCE(adjusted_amount, amount) > 1000000` found 65 rows across TOPS, WHLR, SUNE and CETX; `> 1000` found 322, most of which are scale-consistent pre-split rows. Only 253 `model.features` rows were affected (SUNE, 2021-10-18 through 2022-10-18), and all already had `annualized_dividend IS NULL` because their yield exceeded 25%.
- **Guard:** `src/crispdm/dividend_limits.py`, `scripts/populate_dividend_data.py`, `src/crispdm/features.py`, `scripts/post_nightly_check.py`, `sql/migrations/V0104_quarantine_openbb_dividend_outliers.sql`, `tests/test_populate_dividend_data.py`, `tests/test_features.py`, `tests/test_post_nightly_check.py`
- **Recurrence check:** Run `python -m pytest -q tests/test_populate_dividend_data.py tests/test_features.py tests/test_post_nightly_check.py` before shipping a dividend-ingestion or annualization change, then run `python -m scripts.post_nightly_check --run-date <date>` after a nightly and confirm `openbb_dividend_outliers` is PASS. Any new amount above the ceiling must be quarantined with evidence, never silently deleted.
